## 一、总分计算链路（办法「计分办法」）

**办法条款**：量化总分＝工作业绩标准分×80%＋民主测评得分×10%＋领导评议得分×10%

| 步骤 | 视图/表 | 作用 |
|---|---|---|
| ① 原始分汇总 | `ZCPS_YSFJG`（原始分结果表）→ `V_ZCPS_FS_GXYSF` | 按人汇总各单项原始分：jcf 基础分 / gzlf 工作量分 / gzzlf 工作质量分 / zygzf 专业工作业绩分 / 岗位业绩各分项 |
| ② 序列最高分 | `V_ZCPS_FS_MAX` | 按 **序列(主/辅) × 级别(正高/副高/中级)** 分组取各单项原始分最大值（归一法分母） |
| ③ 标准分转化 | `V_ZCPS_FS_FXBZF` | 单项原始分超上限时 ×上限/最高分：基础15、工作量25、质量10、专业业绩30；岗位业绩各分项上限10（对应办法五项上限 15/25/10/30/20） |
| ④ 最终成绩单 | `V_ZCPS_FS_TJJG` | **总分 = 标准分总分×0.8 + 民主测评分 + 领导评议分**，并按 主系列→辅系列、正高→副高→中级、总分降序 输出 |
| ⑤ 民测/领导得分 | `V_RSC_MZCP` | `ANNUAL_DA_EVALUATION_RESULT` type_='MZCP'，`is_leader='1'`→领导评议 ylddf、`'0'`→民主测评 mzdf（各自取平均；视图中×10%的比例折算体现在得分本身） |
| ⑥ 单项成绩快照 | `T_ZCPS_SCORE_TEA(_VIEW)` / `V_T_ZCPS_SCORE_TEA` | 每人每单项得分快照（rznx/xl/bzgz/bz/ndkh/zcxyfz/lw/ky_jcj/ky_jczz/cgzh/ky_zl/kt_zxkt/ky_cghj/ky_hxkt/jzgz/zdxscs/xgkhzgl/zynlts/jxsjxm/jxpj/gwgzkhjg/fwzlkh/jl/ylddf/mzdf…） |

**通用口径**（各视图共有）：
- 业绩窗口：`b.rdsj < 业绩时间`（rdsj=现职聘任起始月，取自 `V_RSC_GWJP_JSXX`），即「获评现职以来」；
- 流程口径：`ss_process.process_status||process_result = 'FINISHAGREE'`（申报审批通过才计分）；
- 报名口径：`DA129_ZJGWJP`（岗位竞聘报名，`series_id` 01主系列/02辅系列）；新版 `DA129_ZCPS` + `V_ZCPS_BM`。

## 五、测算注意事项

1. **review_id 硬编码**：`V_RSC_MZCP`、`V_RSC_GWGZKHJG`、`V_RSC_FWZLKH` 写死了当年度民测/考核的 review_id（`...5000e` / `...5000f`）。换年度测算必须先改视图里的 ID 或重建。
2. **人员特例硬编码**：`V_RSC_GWJP_JSXX` 中 4 人聘任起始月手工指定；`V_RSC_ZYNLTS` 排除 100165。测算时若名单变化需同步维护。
3. **form_code 硬编码**：`V_RSC_BZGZ` 中教学工作量表单 `form_code='11981c45708c482ca98370e31ee99568'`。
