## 解决：算分引擎 `calc_raw_score`（2026-11-24）

摸底用的 7 条计分 SQL 与合并规则原样搬进服务端（SQL 在 `scoring/sql-templates.json`，与 Python 脚本共用同一份，生成的 SQL 逐字节一致），模型不再算分，只收集入参和解释。

|---|---|
| 本题（李斐斐，摸底算法原样计算） | 17 项全部与基准一致，原始分总分 **41.25**；按办法上限封顶后 38.52（工作质量 12.73 → 10） |
| 83 人整表回归 `npm --prefix server run regress` | 78 人逐格一致；其余 5 人：卢毅=摸底后新审批的表彰、马军元=基准行自身两列不一致、刘瑞锦/冯玉静/邵会=实习管理差异未解释（见 `已知数据现象_视图口径与主档缺失.md`） |
| 端到端（助手用自然问法回答本题） | 分数与引擎逐项一致，并如实说明"与摸底测算表逐项一致"；见 `端到端用例.md` |
