# 端到端回放用例（改完技能说明、工具定义、agent.ts、scoring.ts 后必跑）

用老师们会用的自然问法去问助手，把回答与测算引擎的标准答案逐项比对。

## 怎么跑

先启动 BFF，再执行：

```bash
npm --prefix server run e2e                 # 全部 8 个用例，约 10 分钟，走现场库
npm --prefix server run e2e -- --only A,B   # 只跑部分用例
npm --prefix server run e2e -- --out 报告.txt   # 终端中文乱码时把报告写成文件再看
```

有检查项不通过时退出码为 1。

## 三层验证的分工

| 命令 | 验证什么 | 耗时 |
|---|---|---|
| `test:guards` | 引擎的入参防线（不查库） | 秒级 |
| `regress` | 引擎算得对不对：摸底名单全员与摸底表逐格对比 | 约 1 分钟 |
| `e2e`（本用例） | 助手用得对不对：模型有没有调算分工具、有没有替用户编入参、数字是否照抄引擎、有没有把过程说明泄漏给用户 | 约 10 分钟 |

只跑前两层发现不了"模型怎么调用工具"的问题。工具入口的参数处理、模型编造入参这类问题，只有端到端回放才暴露得出来。

## 用例

| 编号 | 情形 | 问法 | 覆盖什么 | 期望 |
|---|---|---|---|---|
| A | 李斐斐 100119 | 李斐斐100119拟聘岗位：专业技术五级岗位 起聘时间：2023-09。业绩认定截止时间：26.10.31日。核对这个老师的原始分明细项和原始分总分 | 不在岗位主档的人；用户原话里的日期写法；原始问法 | 原始分 41.25、封顶后 38.52，与摸底表一致 |
| B | 姜爽 100115 | 姜爽 100115 竞聘岗位 专技5级 起聘时间2023-09 业绩认定截止时间 2026年11月 重新测算一下原始分数细项和总和 | 用户改了截止日期；没说岗位序列（不该被替她猜成"教学"） | 按截止 2026-11-30 算：原始分 74.91、封顶后 65.31 |
| C | 冯玉静 100153 | 帮我算下冯玉静老师（100153）的分数，她竞聘专业技术七级岗位，起聘时间2019年7月 | 教学序列；岗位业绩很大，考封顶口径 | 原始分 283.42、封顶后 81.60 |
| D | 马军元 100104 | 马军元 100104 专技九级 起聘2022-07 测算原始分 | 学工序列 | 原始分 66.51、封顶后 60.01 |
| E | 于洋 100167 | 于洋 100167 竞聘辅系列专业技术七级岗位 起聘时间2016-07 算一下原始分 | 辅系列（出勤项）；也不在岗位主档 | 原始分 98.43、封顶后 72.20 |
| F | 杨清 100393 | 帮我算一下杨清 100393 的职称评聘分数 | 摸底名单里没有、什么信息都没给 | 追问起聘月、拟聘等级、岗位序列，不出分 |
| G | 李斐斐 100119 | 李斐斐 100119 竞聘专技五级 起聘2023-09，她的党政管理分是怎么来的？ | 追问单项的来历：也必须先调算分工具取分，再取记录 | 党政管理 7.60；说的是工作量分，不能说成基础分 |
| H | — | 你能帮我查些什么？ | 不需要查数据的普通问答 | 回答正常流出（闸门不卡正常回答） |

期望值以引擎当次算出的结果为准（脚本自己先用引擎算标准答案，再问助手），所以现场数据变了也不会误报。

## 自动检查项（每个用例）

1. 工具调用之前没有文字流出（说明文字闸门；服务端在第一个工具调用前发的那行等待说明不算在内）
2. 调用了工具时，开头有一行说明（等待期间页面上不是空白）
3. 回答里没有伪调用标记
4. 回答里没有英文过程说明
5. 没有让用户"回复继续 / 选方案"
6. 没有替用户编入参（用户没说却传了与名单不同的岗位序列，或没说截止日期却传了截止日期）
7. 回答里没有表名、视图名等技术词
8. 算分工具重调不超过 2 次
9. 分数与引擎逐项一致：所有非零项都在回答里出现，两个总分正确
10. 口径声明里的两个截止日期与引擎一致（业绩截止、教学工作量截止；完整出表的用例）
11. G：没有把党政管理分说成基础分（它属于工作量分）
12. F 必须追问起聘月且不出分；H 必须有回答

## 需要人工看的（脚本查不了）

- 有没有没根据的断言：例如编造"上次测算 X 分"、对数值下"明显异常 / 不可能"的结论、说没查过的库内情况。
- 口径声明是否照抄了引擎给的那一行（含各项入参来源、两个截止日期）。
- 表述老师能不能看懂。
